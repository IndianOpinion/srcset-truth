# Examples

| File | What it shows | How to run |
|---|---|---|
| `worked-example.php` | Compiles the card spec and computes the PRD's worked example (412 px phone, DPR 2) without WordPress | `php examples/worked-example.php` |
| `theme-width-map.php` | A theme's width map and slot rules | Copy into `functions.php` or a site plugin |
| `theme-slot-api.php` | Naming slots where a template renders images | Copy into a template |
| `mu-plugin-loader.php` | The one-line must-use loader | Copy to `wp-content/mu-plugins/` |
| `purge-on-create.php` | Purging a page cache when a sibling appears | Copy into a site plugin and adapt |
